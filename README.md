This is a simple MIDI driven visual application that runs in any browser and is driven by either MIDI or the buttons on the screen.

A short video of some of what it can do is at https://www.youtube.com/watch?v=AWUls36mKEY

It is intended as a backdrop, visual prototype for the compositions of Jill Fraser.

It needs to be art directed and tested with various MIDI devices.  That has not happened yet.
